Guide to the Files in this directory:

1. Body/Old Code: Contains Arduino code that old groups used.

2. Continuous Spin Tests: Old code to test the motors. Probably not working anymore due to the changes we made.

3. Dome: Old Arduino code for the head system.

4. Remote: Old code to control BB8 using a phone.

5. Scampa123s BB8 Code: More old code written for Arduino.

6. Test Files: Old files that we developed in Python. Might be worth looking at if needing some ideas or wanting to figure out how system works.
