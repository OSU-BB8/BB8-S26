Guide to the Files in this Directory:

1. Archive: Contains all the old, obsolete code for the project. Some are python files we developed, and others are C files for the Arduino from further back.

2. Body Files: Contains all the files to be used by the Body Pi.

3. Camera Files: Contains all the files to be used by the Head Pi.

4. Demo Videos: Contains videos that we got from demonstrations.

5. Expo Demo: Contains code that was used by the Head Pi for demonstrations.
